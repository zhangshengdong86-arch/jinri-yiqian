# assets/ 图片目录

把图片按**文件名**放进对应子目录，重新编译即生效，不用改代码。

完整文件名清单、尺寸规范、CDN 与包体积说明见 → `docs/图片植入手册.md`

```
assets/
├── brand/        品牌 logo + 四个类目入口图标（5 个）
├── divination/   卜卦：铜钱、卦画框、页头水墨（3 个）
├── zodiac/       星座：12 主视觉 + 12 符号 + 今日卡（25 个）
├── palm/         手相：页头、入口图标、三条主线、拍摄引导等（9 个）
├── tarot/        塔罗：页头、牌背、牌面 0–77（80 个）
└── share/        分享海报模板（预留，暂未接入）
```

规则：
- 文件名全小写 + 下划线，**一字不差**
- 格式用 PNG（透明通道）或 WebP，**不要用 SVG**（小程序 image 对各平台支持不一致）
- 深色页面（星座 / 塔罗）素材必须透明背景或深色底

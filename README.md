# 今日宜签 · 网页版

> 微信小程序「今日宜签」（卜卦 / 星座 / 手相 / 塔罗 + 每日一签，17 个页面）的**纯静态网页转写版**。
> 双击 `index.html` 即可在浏览器中使用：无后端、无账号、数据只存本机浏览器。
> 全部结果由预设规则与本地内容库生成，**仅供娱乐**，不构成任何决策依据。

---

## 一、如何运行

1. **直接双击 `index.html`**（推荐，无需安装任何东西）；
2. 可选：在项目目录起个本地静态服务器（`python -m http.server` 或 VS Code Live Server），访问 `http://localhost:8000/`，体验与双击完全一致。

数据保存在浏览器 localStorage 里（键名与原小程序一致：`sg_history` / `sg_favorite` / `sg_daily_v1` 等），清浏览器缓存即清数据。

## 三、转写方式与差异说明

网页版由微信小程序源码（`source/miniprogram/`，原封未动）**手工转写**而来：

- WXML → JS 渲染函数（`render()` 模板），WXSS → CSS（rpx 已按 1rpx = 0.5px 换算）；
- `wx.*` API → `js/core.js` 里的浏览器兼容层（存储 / 路由 / 弹层 / 导航栏 / canvas 长图）；
- 页面路由 → URL hash 路由（`#/pages/xxx`），可刷新、可回退。

**有意为之的差异（与真机小程序的差别）：**

1. **手相拍照识别**：小程序里依赖微信云函数做 AI 识图；网页版无云环境，拍照后执行**本地质量校验**，解读结果走原小程序的「mock 示例引擎」并明确标注「当前为示例结果」；建议用**手型自测**获得更贴合的回答。
2. **音效**：触感震动与提示音不适用于普通网页，已空实现（原逻辑保留在 `source/`）。
3. **分享**：小程序是转发卡/长图；网页版把分享长图画到隐藏 canvas 后以 **PNG 下载**替代（按钮文案仍为「生成分享图」）。
4. **导航栏**：网页版顶部有自制导航栏，返回键与浏览器后退键都可用；主题色随类目自动切换（与小程序一致）。

## 四、目录结构

```
jinri-yiqian-web/
├── index.html          入口（双击它）
├── TRANSFER_SPEC.md    转写规范（开发文档）
├── css/
│   ├── tokens/themes/base/ui.css   全局设计系统与网页壳
│   └── pages/*.css                 每页样式（按路由动态装载）
├── js/
│   ├── core.js          运行时：wx 兼容层 / 路由 / 组件渲染器
│   ├── modules/         数据与工具（卦辞·签诗·牌义·主题·存储等）
│   └── pages/           17 个页面（逻辑照搬原页面 js）
├── assets/              全部图片（塔罗 78 牌面等，本地文件）
├── scripts/check.js     本地自检（node scripts/check.js）
└── source/              微信小程序原项目（只读备份，含 pages/utils/组件/云函数）
```

## 五、自检

```bash
node scripts/check.js          # 全量自检：语法/加载/17页渲染/data-act/data完整性
node scripts/check-assets.js   # 图片引用完整性（渲染输出 vs assets/ 磁盘文件）
```
全部 ✓（0 失败）即为通过：check.js 会加载全部 JS、逐页执行 onLoad/render、核对事件绑定、
数据完整性（64 卦 / 78 塔罗牌 / 12 星座 / 103 签诗 / 链接格式回环）与禁用项；
check-assets.js 确认渲染使用的每张图片都真实存在于 assets/ 目录。
